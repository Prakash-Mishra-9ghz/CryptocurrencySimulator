# AI Portfolio Insights

## What this is

A free-form question box (on the Portfolio page) where the user asks
about their own portfolio in plain English — "How is my portfolio
performing?", "Which holding is doing best?" — and gets a real answer
generated by an LLM (via Groq's free API), grounded in the user's
**actual** portfolio and last 10 transactions.

This is a genuine retrieval + generation feature, not a scripted
response: the backend fetches the user's real data, includes it in the
prompt, and the model answers using only that data.

## Design

- **`src/services/aiInsightsService.js`** — `askAboutPortfolio(userId, question)`:
  1. Validates the question (non-empty string) — fails fast, no DB/network call for invalid input.
  2. Confirms `GROQ_API_KEY` is configured — fails fast with a clear 503 if not, before touching the database.
  3. Fetches the user's real portfolio (`computePortfolio`) and last 10 transactions.
  4. Sends both as JSON context to Groq's chat completions API, with a system prompt that explicitly forbids inventing numbers not present in that data and keeps every answer framed as simulation-only (never real financial advice).
- **`POST /api/insights/ask`** — `{ "question": string }` → `{ "answer": string, "model": string }`

## Setup

1. Get a free API key at [console.groq.com/keys](https://console.groq.com/keys) — no card required.
2. Set `GROQ_API_KEY` in your backend `.env`.
3. `GROQ_MODEL` defaults to `openai/gpt-oss-20b`. **Groq's free-tier model lineup changes fairly often** (models get deprecated with only weeks of notice) — if you get a "model not found" error, check the current list at [console.groq.com/docs/models](https://console.groq.com/docs/models) and update `GROQ_MODEL` accordingly. No code change needed, just the env var.

## Rate limits to know

Groq's free tier is generous (roughly 1,000-14,400 requests/day
depending on the model) but not unlimited. Fine for a student project
demo; if you hit a rate-limit error during heavy testing, wait a bit or
switch to a different free model via `GROQ_MODEL`.

## What this is NOT

- Not financial advice — the system prompt explicitly says so, and the UI shows a disclaimer under every answer.
- Not a general-purpose chatbot — it only has access to the asking user's own portfolio/transaction data, nothing else.
- Not guaranteed to never hallucinate — LLMs can still misinterpret a question even when grounded in real data. The system prompt reduces this (explicit "only use provided numbers" instruction) but doesn't eliminate it entirely; this is worth mentioning honestly in a viva if asked about limitations.

## Test coverage

`backend/tests/unit/aiInsights.unit.test.js` — 5 tests covering input
validation (empty/whitespace/missing/non-string question) and the
missing-API-key fail-fast path, all without needing a database or
network call. The actual LLM call itself isn't unit-tested (would
require a real API key and network access) — test it manually by
asking a question through the UI once `GROQ_API_KEY` is set.
